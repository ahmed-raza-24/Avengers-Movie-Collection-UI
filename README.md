# Avengers-Movie-Collection-UI
A visually rich **Avengers / Marvel movie collection** built using **pure HTML &amp; CSS**, featuring animated **conic-gradient borders**, character-based color themes, and glowing box-shadows.

## 🚀 Features

- 🎬 Complete Marvel & Avengers movie timeline layout  
- 🎨 **Character-based color themes**  
  - Iron Man → 🔴 Red  
  - Hulk → 🟢 Green  
  - Thor → 🟡 Yellow  
  - Black Panther → 🟣 Purple  
  - Captain America → 🔵 Blue  
  - Avengers → 🌈 Multicolor (Red, Yellow, Blue, Green)  
- ✨ Smooth animated **conic-gradient rotating borders**
- 💡 Neon glow box-shadow effects
- 📱 Responsive & modern UI design
- ❌ No JavaScript — **CSS only animation**

---

## 🛠 Tech Stack

- **HTML5**
- **CSS3**
  - Flexbox
  - `@property`
  - `conic-gradient`
  - Keyframe animations
